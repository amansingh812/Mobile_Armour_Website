# 🔧 Sitemap Fix - Quick Guide

## What Was Wrong

1. **`next-sitemap` was overriding your custom `sitemap.ts`**
   - Your `sitemap.ts` has MongoDB integration and correct URLs
   - But `next-sitemap` was scanning files and creating wrong URLs

2. **Category URLs were broken**
   - Generated: `/category/products%3Fcategory=Cases` ❌
   - Should be: `/products?category=Cases` ✅

3. **No product pages in sitemap**
   - Your `sitemap.ts` fetches from MongoDB but wasn't being used

## ✅ What Was Fixed

### 1. Updated `next-sitemap.config.js`
- **Now**: Only generates `robots.txt` (not sitemap files)
- **Excludes**: Everything (`exclude: ['*']`)
- **Result**: Your `sitemap.ts` handles all sitemap generation

### 2. How It Works Now

```
┌─────────────────────────────────────────┐
│  Next.js Build Process                  │
├─────────────────────────────────────────┤
│  1. Runs `next build`                   │
│     └─> Generates sitemap from          │
│         /src/app/sitemap.ts              │
│         (includes MongoDB products)      │
│                                          │
│  2. Runs `postbuild` script              │
│     └─> Runs next-sitemap                │
│         (only generates robots.txt)      │
└─────────────────────────────────────────┘
```

## 🚀 How to Rebuild

### Step 1: Clean old files
```bash
rm -rf public/sitemap*.xml public/robots.txt
```

### Step 2: Rebuild
```bash
npm run build
```

### Step 3: Verify files created
```bash
ls -la public/sitemap*.xml public/robots.txt
```

You should see:
- ✅ `public/sitemap.xml` - Generated by Next.js from your sitemap.ts
- ✅ `public/robots.txt` - Generated by next-sitemap

## 📋 What Your Sitemap Will Include

### From `sitemap.ts` (MongoDB-powered):

1. **Static Pages** (7 pages)
   - `/` (priority: 1.0, daily)
   - `/products` (priority: 0.9, daily)
   - `/services` (priority: 0.8, weekly)
   - `/contact` (priority: 0.8, monthly)
   - `/about` (priority: 0.7, monthly)
   - `/price` (priority: 0.7, weekly)
   - `/faq` (priority: 0.6, monthly)

2. **Category Pages** (5 pages)
   - `/products?category=Cases` (priority: 0.85, daily)
   - `/products?category=Power%20Banks` (priority: 0.85, daily)
   - `/products?category=Car%20Holders` (priority: 0.85, daily)
   - `/products?category=Cables%20%26%20Adapters` (priority: 0.85, daily)
   - `/products?category=Screen%20Protectors` (priority: 0.85, daily)

3. **Product Pages** (Dynamic from MongoDB)
   - `/products/{product_id}` (priority: 0.75, weekly)
   - Uses actual product `updatedAt` timestamps
   - Automatically updates when products change

## 🔍 Troubleshooting

### Issue: Sitemap still shows old URLs
**Solution:**
```bash
# Clear Next.js cache
rm -rf .next
# Clear public files
rm -rf public/sitemap*.xml public/robots.txt
# Rebuild
npm run build
```

### Issue: Products not showing in sitemap
**Check:**
1. MongoDB connection is working
2. Products exist in database
3. Check build logs for errors

### Issue: Sitemap not accessible
**Check:**
1. File exists: `ls public/sitemap.xml`
2. Permissions: `chmod 644 public/sitemap.xml`
3. Deployment copied public folder
